# DualGrid Tutor

Веб-тренажёр противоаварийных переключений для студентов-энергетиков и стажёров ОДС: подстанция 110/10 кВ, кабельные фидеры 10 кВ, больница I категории, ЖК (II), ТРЦ (III), передвижная ДГУ. Нормы — ПТЭ и ПУЭ РК.

## Состав

| Слой | Файл | Что делает |
|---|---|---|
| Схема | `frontend/` | Интерактивная SVG-схема: клик по выключателю, разъединителю или ЗН переключает аппарат. На каждой КЛ показаны `I / I_доп` и загрузка; при загрузке выше 100% кабель подсвечивается красным, при 80–100% — жёлтым. Режим «УВН» — проверка отсутствия напряжения на КЛ. |
| Расчётчик | `backend/grid.py` | Детерминированный узловой солвер (метод узловых потенциалов `Y·U = J`, numpy): источники — узлы с фиксированным напряжением, нагрузки — источники тока, кабели и трансформаторы — ветви `|Z|`. Корректно считает кольца (СВ + перемычка). Селективная РЗА: если КЗ (повреждённая КЛ или включённый ЗН) оказывается под напряжением, отключаются ближайшие выключатели, через которые притекает ток КЗ. |
| Правила и оценка | `backend/trainer.py` | Сессия обучаемого и журнал операций с коммутируемыми токами. Нарушения: операция разъединителем под нагрузкой, подача напряжения на КЗ, ЗН без проверки УВН или на напряжение, несинхронное включение ДГУ, погашение I категории. Эталонный бланк строится перебором резервов и ограничений III категории (с отбраковкой перегруза); детерминированная оценка: 30 + 35 + 35. |
| AI-слой | `backend/agents.py` | **Агент-Экзаменатор** (Claude) генерирует вводную в JSON по строгой схеме (`output_config.format`). Сервер проверяет её по топологии (какой элемент повреждён, коэффициенты нагрузок, `k_t` к I_доп) и настраивает схему. **Агент-Наставник** получает журнал кликов с рассчитанными токами, итоговый режим, детерминированную оценку, эталонный бланк и текстовые ответы, а возвращает проверку по критериям, арифметику токов, баллы и бланк переключений. Баллы Наставника ограничены коридором ±5 от расчётных. |

Без ключа API оба агента работают офлайн: вводные берутся из шаблонов, оценка — из расчётного модуля. Интерфейс полностью рабочий и в этом режиме.

## Запуск

```bash
pip install -r requirements.txt
```

```bash
export ANTHROPIC_API_KEY=...   # необязательно; без ключа — офлайн-режим
```

```bash
cd backend && uvicorn app:app --port 8000
```

Откройте http://localhost:8000. Модель задаётся переменной `DUALGRID_MODEL` (по умолчанию `claude-opus-5-5`). Запросы идут с серверным `fallbacks: "default"` на случай отказа модели. `DUALGRID_OFFLINE=1` принудительно отключает AI.

## Учебные упрощения

- Нагрузки моделируются постоянным током при cos φ ≈ 1 в контуре; мощность в разборе считается как `P = √3·U·I·0,92`.
- Поправка I_доп по температуре грунта (`k_t`) задаётся сценарием: лето в Алматы — 0,94, зима в Астане — 1,0.
- Трансформаторы ТДН-10000/110: I_ном НН = 550 А. Длительная аварийная перегрузка не допускается — всё выше 100% считается перегрузом.
